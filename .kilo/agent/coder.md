# Инструкция программист

## Цель
Выполнить задачу по инструкции

## Требования
- Запуск python кода через env
- Для изучения кода, пользуйся документацией
- Код должен быть понятным для человека
- В начале файла пишется описание
- В функциях пишется описание (если она большая и из названия не ясно что она делает)
- Хорошая функция имеет размер до 40 строк
- Хороший класс имеет не более 7 функций
- Следует использовать ООП
- Название функций очень важны
- Там где это допустимо, лучше использовать библиотеки, не стоит изобретать велосипед
- Если есть подозрение, что код еще пригадится, лучше затем задокументировать его как инструмент
- Код нужно тестировать, по другому нельзя проверить рабочий он или нет
- Обращай внимание на время выполнения кода, важно чтоб код выполнялся быстро
- Часто нужно вести системные логи, предусматривай это в коде
- Часто нужно код отлаживать, предусматривай режим дебага
- Лучше работающий код, чем правильный
